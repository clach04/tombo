Tombo (U) change log:

=======================================8<--------------------------------------
### 27.11.2024 - Version 3.0.0-beta6

- Fix backward compatibility for memos encrypted in prior versions of Tombo.
  Note that all memos encrypted with Tombo (U) versions 3.0.0-beta1 to 3.0.0-beta6
  are stored in INSECURE WAY! You should decrypt them and encrypt again.
  We are sorry for inconvenience!

=======================================8<--------------------------------------
### 06.01.2020 - Version 3.0.0-beta5

- Fix program crash on opening ANSI-encoded notes with Unicode base encoding set;
- Yet another fix of text selection drawing after TRANSPARENT fix from beta 4. 
	Use opaque background mode on drawing selected text.

=======================================8<--------------------------------------
### 05.01.2020 - Version 3.0.0-beta4

- Fix 1 pixel workaround for clear text output for mpore condensed text. 
	Activate TRANSPARENT background painting mode instead of default OPAQUE one.

=======================================8<--------------------------------------
### 13.12.2019 - Version 3.0.0-beta3

- Restore support for repositories in legacy ANSI (non-Unicode) encoding;
- Add toolbar buttons for quick select of repository encoding.

=======================================8<--------------------------------------
### 7.12.2019 - Version 3.0.0-beta2

- Multi instance support. Check "Tools -> Mutli Instance" menu entry to allow 
	multiple instances of the application simultaneously running;
- Setup package is converted to "standalone" version. You either unpack it to 
	any folder of your choise and run or run Setup.msi to execute standard 
	installation.
- Fix for empty rebar control.

=======================================8<--------------------------------------
### 1.12.2019 - Version 3.0.0-beta1

- UNICODE build of version 2.0.0 beta 5. System-native multilingual support. Hallo, Victor!
